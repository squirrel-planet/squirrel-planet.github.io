New Bee Lang

警告：本编程语言会让你怀疑人生

New Bee Lang 是一门专为折磨程序员而设计的恶搞编程语言。它以蜜蜂为主题， 充满了对开发者的无情嘲讽和难以理解的语法规则。如果你想体验被蜜蜂支配的恐惧， 欢迎来到 New Bee Lang 的世界！

核心特性

New Bee Lang 不仅仅是一门编程语言，它更是一种生活态度

强制问候系统

程序必须以 hello New Bee Lang 开头，以 goodbye New Bee Lang 结尾。忘记问候？蜜蜂们会毫不留情地拒绝执行你的代码，并送上一段尖酸刻薄的批评。

please 语句占比

你的代码中必须有 40% 到 50% 的代码行是 please 语句。这是蜜蜂们用来维持世界平衡的方式，也是对你意志力的考验。每写五个语句，就必须插入一个 please 语句。

业界领先的嘲讽系统

当你的代码出错时，蜜蜂们会打印出精心准备的嘲讽信息，从「这代码比我奶奶的食谱还难懂」到「你的键盘是不是被蜜蜂蜇过」，每一句都直击心灵。

使用指南

只需一个 Python 解释器，即可开始你的噩梦之旅

1

下载 New Bee Lang 解释器

下载 New Bee Lang 解释器到你的本地目录。你需要确保 New_Bee_Lang.py 文件存在于你的工作目录中。

2

运行你的程序

使用以下命令运行你的 New Bee Lang 程序：

python New_Bee_Lang.py your_program.nbl

语法规则

通往成功的必经之路，请仔细阅读

强制性问候与告别

每一个 New Bee Lang 程序都必须以 hello New Bee Lang 开头，以 goodbye New Bee Lang 结尾。这些语句必须一字不差，包括大小写。忘记问候？程序拒绝运行。忘记告别？程序拒绝运行。蜜蜂们对礼仪的要求就是这么严格。

please 语句占比

please 语句必须占所有有效代码行的 40% 到 50%。如果低于 40%，蜜蜂们会认为你不够礼貌。如果高于 50%，蜜蜂们会认为你只会说「请」而不会做实事。此外，不能连续出现超过 5 行非 please 语句。

有效字符限制

New Bee Lang 有效字符包括：字母、数字、空格、#、+、-、*、/、"、' 以及 NBL 三个大写字母。如果你胆敢使用其他「非法字符」，蜜蜂们会打印出一段专门针对该字符的嘲讽。

注释支持

New Bee Lang 支持行内注释，使用 # 符号标记。# 之后的所有内容都将被视为注释，不会被解释执行。

蜂蜜与偷懒系统

蜂巢初始有 5 点蜂蜜。lay egg 和 eat（幼蜂进食）各消耗 1 点蜂蜜，蜂蜜耗尽后无法产卵！使用 get honey 命令让工蜂获取蜂蜜。此外，每条指令执行后工作蜂会自动偷懒，需使用 do not slack 命令让它保持工作状态。

do not give up 机制

除了 hello 命令外，每执行一条指令后都会触发「放弃检测」，若未使用 do not give up 命令，程序会直接报错退出！do not give up 的效果持续 5 条指令，请及时补充。

命令参考

每个命令都与蜜蜂的生活习性相关，请仔细阅读

init honeycomb
初始化蜂巢，创建包含蜂后（queen bee）的蜂巢栈。每个程序的起点，只能执行一次。
call
从蜂巢中取出一项，放入工作区。通常用于取出蜂巢顶部的蜜蜂。
lay egg
在工作区中的蜂后产下一枚卵。消耗 1 点蜂蜜，要求工作区顶部必须是蜂后。
sleep
让蜂巢顶部的蜜蜂成长。卵→幼蜂
eat
让蜂巢顶部的幼蜂吃蜂蜜成长。幼蜂→蜜蜂，消耗 1 点蜂蜜。
kill
移除蜂巢顶部的蜜蜂。但不能移除蜂后，否则程序立即终止。
all kill
清空整个蜂巢。不可逆的操作，请三思而后行。
go back
将工作区顶部的蜜蜂放回蜂巢。保持蜂巢的秩序。
get honey
让工蜂获取 1 点蜂蜜。要求工作区顶部必须是工蜂。
set type bee
将蜂巢顶部的普通蜜蜂设置为 bee 类型。
set type worker bee
将蜂巢顶部的 bee 设置为工蜂。工蜂可以执行计算和输出等任务。有值的蜜蜂不能设置为工蜂。
set value '*' / set value "*"
为蜂巢顶部的蜜蜂设置一个单字符值。值可以用单引号包裹或直接写。
set value input
通过输入为蜂巢顶部的蜜蜂设置一个单字符值。
set value random
为蜂巢顶部的蜜蜂设置一个随机数字值（0-9）。
output
输出蜂巢顶部蜜蜂的值。要求工作区顶部必须是工蜂。
compute +
加法运算。蜂巢顶部两个数字相加，结果存入 next_bee_value。
compute -
减法运算。蜂巢顶部两个数字相减（顶部减第二顶）。
compute *
乘法运算。蜂巢顶部两个数字相乘。
compute /
除法运算。蜂巢顶部两个数字相除。
loop start / loop end
循环结构。循环体内的代码会被重复执行。要求工作区顶部必须是工蜂。
judgment start / judgment end
条件判断结构。检查蜂巢顶部蜜蜂的值是否为非 '0'。要求工作区顶部必须是工蜂。
give up
立即终止程序。打印告别信息并退出。
do not give up
防止程序因「放弃检测」而报错，效果持续 5 条指令。
do not slack
防止工作蜂在指令执行后自动偷懒，效果持续 5 条指令。
swap
交换工作区顶部两项的位置。
error
遍历蜂巢，将所有蜜蜂的值拼接后作为错误信息输出并终止程序。
please
最独特的命令。放在其他命令前表示「礼貌地请求」。每5个命令必须插入一个。

错误处理

当你犯错时（这是必然会发生的），系统会打印出一段精心设计的嘲讽信息

!

嘲讽系统

错误信息通常包含随机选择的嘲讽语，如「这代码比我奶奶的食谱还难懂！」或「如果代码能哭，它现在正在嚎啕大哭。」这些话语旨在让你感到自己的渺小和无能。

然后是具体的错误描述，指出你在哪里犯了什么错误。最后是一段「鼓励」话语，如「继续加油！你快要理解了... 才怪！」
